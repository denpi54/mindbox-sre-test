# Mindbox SRE Test Task

## 📌 Условие

Веб-приложение в Kubernetes с дневным циклом нагрузки. Требования:
- отказоустойчивость
- минимальное потребление ресурсов ночью
- быстрая инициализация (5–10 сек)
- потребление CPU: 0.1 после запуска, выше — при старте
- 128Mi памяти стабильно
- кластер мультизональный, 5 нод
- 4 пода выдерживают пиковую нагрузку

## 📁 Состав

- `k8s/deployment.yaml` — deployment с affinity, readinessProbe, rolling update
- `k8s/hpa.yaml` — autoscaling по CPU (1–4 реплики)
- `k8s/pdb.yaml` — защита от удаления всех подов одновременно

## 🚀 Установка

```bash
kubectl apply -f k8s/
```

## 🧠 Комментарии к решениям

- `readinessProbe`: отложенный старт из-за инициализации
- `cpu requests = 500m`, `limits = 1`: учли всплески при запуске
- `HPA`: учитывает дневную нагрузку, min=1 ночью
- `anti-affinity`: поды в разных зонах (или хостах)
- `rollingUpdate`: нулевая недоступность при развёртывании

## 🗒️ Замечания

- `topologyKey` можно заменить на `kubernetes.io/hostname`, если нет зон
- `image` нужно заменить на реальный
